# HACKER ANKIT — GitHub Pages

A neon animated demo landing page with a safe link to Instagram's official login page.

## Publish
1. Create a GitHub repository.
2. Upload `index.html`.
3. Open Settings → Pages.
4. Under Build and deployment choose `Deploy from a branch`.
5. Select `main` and `/root`, then Save.
6. Wait for GitHub Pages to publish the site.

This project does not collect, guess, or brute-force passwords.
